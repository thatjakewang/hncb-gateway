# 華南銀行金流介接外掛

WooCommerce 信用卡金流模組,介接華南銀行 ePOS 線上授權平台。支援測試/正式環境切換,相容 WooCommerce HPOS(高效能訂單儲存)。

- **版本**:1.0.0
- **付款方式**:信用卡一期付款(尚未支援分期)
- **開發**:群輝商務科技 Jake Wang

---

## 一、系統需求

| 項目 | 需求 |
|------|------|
| WordPress | 5.8 以上 |
| WooCommerce | 6.0 以上(建議 8.2+) |
| PHP | 7.4 以上 |
| HPOS | 已相容,開啟或關閉皆可運作 |

需先向華南銀行申請特店,取得以下資料才能設定:特店代號、特店代碼、特店通行碼、端末代號,以及測試環境授權網址。

---

## 二、安裝

1. 將 `hncb-gateway.php` 上傳至 `/wp-content/plugins/hncb-gateway/` 目錄。
2. 進入 WordPress 後台 →「外掛」→ 啟用「華南銀行金流介接」。
3. 進入 WooCommerce →「設定」→「付款」分頁,找到「華南銀行金流」並點「管理」進入設定。

---

## 三、後台欄位設定說明

進入 WooCommerce →「設定」→「付款」→「華南銀行金流」後,各欄位說明如下:

| 欄位 | 說明 | 資料來源 |
|------|------|----------|
| **啟用 / 停用** | 勾選後此付款方式才會出現在結帳頁。**設定未完成前請勿啟用。** | — |
| **結帳顯示名稱** | 顧客在結帳頁看到的付款方式名稱,預設「銀行線上刷卡」,可自訂。 | 自訂 |
| **連線環境** | 選擇「測試環境」或「正式環境」。導入新客戶務必先用測試環境驗證。 | 自選 |
| **正式環境授權網址** | 華南正式環境網址,已預填 `https://eposn.hncb.com.tw/transaction/api-auth/`,一般不需更動。 | 預設值 |
| **測試環境授權網址** | 華南提供的測試環境網址,**需自行填入**。選「測試環境」時才會使用。 | 銀行提供 |
| **公司名稱**(merchantName) | 顯示於授權頁的特店名稱。 | 銀行提供 |
| **特店代號**(merchantID) | 華南核發的特店代號。 | 銀行提供 |
| **端末代號**(terminalID) | 8 位數字,儲存時會自動檢查格式。 | 銀行提供 |
| **特店代碼**(merID) | 華南核發的特店代碼。 | 銀行提供 |
| **特店通行碼**(checkID) | 用於計算驗證碼的密鑰,欄位以密碼形式遮蔽。**請妥善保管,勿外洩。** | 銀行提供 |

> ⚠️ 「特店通行碼」是整個金流驗證的核心密鑰,等同密碼。交接時請透過安全管道傳遞,不要寫在公開文件或聊天訊息中。

## 四、測試 / 正式環境切換流程

導入新客戶時,**一律先在測試環境完整驗證一輪**,再切換正式環境。

### 步驟 1:設定測試環境

1. 「連線環境」選擇 **測試環境**。
2. 「測試環境授權網址」填入華南提供的測試網址。
3. 填入測試用的特店代號、特店代碼、端末代號、特店通行碼(測試環境的特店資料通常與正式不同,請向銀行確認)。
4. 儲存。若漏填測試網址或端末代號格式錯誤,後台會跳紅字提醒。

### 步驟 2:測試刷卡

1. 暫時勾選「啟用」,讓付款方式出現在結帳頁。
2. 用測試商品下單,選「銀行線上刷卡」結帳。
3. 系統會自動轉址到華南測試授權頁,使用銀行提供的**測試卡號**完成授權。
4. 確認以下三點:
   - 授權成功後訂單狀態正確變更(見第六節)。
   - 訂單備註出現信用卡末四碼、授權金額、交易序號、授權碼。
   - 「感謝訂購」頁正確顯示信用卡資訊。
5. 另外測一筆失敗情境(例如用會被拒絕的測試卡),確認訂單轉為「失敗」且備註有錯誤原因。

### 步驟 3:切換正式環境

1. 測試全部通過後,「連線環境」改為 **正式環境**。
2. 將四項特店資料**替換為正式環境的值**(代號、代碼、端末代號、通行碼)。正式環境授權網址保持預設即可。
3. 儲存,確認「啟用」為勾選狀態。
4. 上線後建議用真實小額(例如最低金額商品)實刷一筆驗證,確認金流入帳,再行對外開放。

> 切換環境只需改「連線環境」選項與對應的特店資料,程式碼不需更動。

## 五、付款流程運作原理(供維護參考)

1. 顧客結帳選擇此付款方式 → 導向 WooCommerce 付款頁。
2. 付款頁產生一張隱藏表單,內含特店資料與依華南規格計算的 `checkValue`,自動 POST 至授權網址。
3. 顧客在華南頁面輸入卡片資訊完成授權。
4. 華南將授權結果 POST 回網站的回呼網址:
   ```
   https://你的網域/wc-api/bank_cc_result_callback
   ```
5. 外掛**先驗證回傳的 `checkValue`**(用 `hash_equals` 比對),驗證通過才寫入訂單資料並更新狀態,最後將顧客導回「感謝訂購」頁。

驗證未通過的回呼會被直接拒絕(HTTP 400),並在訂單留下備註,可防止偽造請求竄改訂單。

## 六、訂單狀態與資料

### 授權成功
- 訂單狀態:透過 `payment_complete()` 自動轉為 **處理中(processing)** 或 **已完成(completed)**(依商品類型;純虛擬/可下載商品會直接完成)。
- 自動扣減庫存、清空購物車。

### 授權失敗
- 訂單狀態轉為 **失敗(failed)**,訂單備註記錄錯誤代碼與失敗原因。

### 寫入的訂單欄位(meta)
外掛會在訂單上儲存以下欄位,可於程式中以 `$order->get_meta()` 讀取:

| 欄位 | 內容 |
|------|------|
| `_hncb_authAmt` | 授權金額 |
| `_hncb_xid` | 交易序號 |
| `_hncb_Last4digitPAN` | 卡號後四碼 |
| `_hncb_authCode` | 授權碼(成功時) |
| `_hncb_authresponse` | 授權結果(成功/失敗) |
| `_hncb_errcode` | 錯誤代碼(失敗時) |
| `_hncb_errDesc` | 失敗原因(失敗時) |

## 七、常見問題

**Q：結帳頁看不到「銀行線上刷卡」選項?**
請確認:(1) 外掛已啟用;(2) 付款設定中「啟用」已勾選;(3) 特店資料、授權網址都已填妥(設定不完整時付款頁會顯示「金流設定不完整」並擋下)。

**Q：付款頁顯示「金流設定不完整」?**
表示授權網址、特店通行碼、特店代號、端末代號、特店代碼其中有空值,回後台補齊即可。

**Q：儲存設定時跳出「端末代號應為 8 位數字」?**
端末代號必須是 8 碼純數字,請向銀行確認後重填。

**Q：刷卡成功但訂單顯示失敗?**
外掛會額外比對「授權金額是否等於訂單金額」,若不符會判定失敗。請檢查訂單金額是否在轉址後被改動,或確認測試環境特店設定是否正確。

**Q：升級 WooCommerce 後外掛是否還能用?**
本版本已宣告相容 HPOS,WooCommerce 後台不會再標示為不相容,可正常運作。

**Q：可以做分期付款嗎?**
目前版本僅支援一期付款。分期需調整送出參數(`txType`、`autoCap` 等),如有需求請聯絡開發者。

## 八、版本紀錄

### 1.0.0
- 宣告相容 WooCommerce HPOS,訂單資料改用 `get_meta()` / `update_meta_data()`。
- 回呼改為「先驗證、後寫入」,並以 `hash_equals()` 比對驗證碼,修正原先可被竄改的順序問題。
- 所有回呼輸入皆做淨化,付款表單輸出皆做跳脫。
- 新增測試/正式環境切換與授權網址設定欄位。
- 新增授權金額比對、防重複處理、端末代號格式驗證。
- 補上 text domain。
